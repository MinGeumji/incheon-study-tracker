2027 인천 공기업 8주 진도관리 PWA

1. 이 폴더의 파일 전체를 HTTPS 웹 호스팅(GitHub Pages, Netlify 등)에 업로드합니다.
2. 안드로이드 Chrome에서 배포된 HTTPS 주소를 엽니다.
3. 브라우저 메뉴 > 앱 설치 또는 홈 화면에 추가를 누릅니다.
4. 설치 후 오프라인에서도 열 수 있고 완료 체크 및 메모는 해당 기기에 저장됩니다.

주의: index.html을 파일로 직접 열면 PWA 설치/오프라인 캐시가 작동하지 않습니다. HTTPS 배포가 필요합니다.
